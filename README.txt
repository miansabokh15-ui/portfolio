DEMO TIMER NOTE:
A client-side JavaScript timer can make a portfolio demo automatically close after 5 minutes, but it is not secure because visitors can inspect/modify browser code. For a real expiring demo link, deploy the project behind a server/session system that issues a short-lived token/session (for example 5 minutes) and rejects expired sessions.
