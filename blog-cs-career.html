My Journey into Computer Science Career

A personal journey through programming, C++, OOP, SQL, projects, certifications, university, AI, internships, challenges, and future goals.

Eliott

UI/UX Designer & Frontend Developer

Why I chose Computer Science

Choosing a career path is one of the biggest decisions a student makes. For me, Computer Science became interesting because technology is not just something we use every day; it is something we can build, improve, and use to solve real-world problems.

I wanted to understand what happens behind applications, websites, databases, and the systems we interact with. That curiosity became the starting point of my journey into Computer Science.

"Computer Science is not only about learning a programming language. It is about learning how to think, solve problems, and build useful solutions."

Starting with programming

My journey started with the basics of programming. At first, programming felt challenging because every small task required careful thinking. I had to learn how variables, conditions, loops, functions, and data structures work together.

With practice, I started to understand that programming is less about memorizing code and more about breaking a problem into smaller steps and solving each step logically.

C++

C++ became one of the important programming languages in my learning journey. It helped me understand programming fundamentals as well as concepts such as pointers, arrays, functions, structures, file handling, and memory management.

Working with C++ also taught me that writing code is only one part of programming. Understanding how the code works internally is equally important.

#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 20;

    cout << "Sum = " << a + b << endl;

    return 0;
}

OOP

After learning programming fundamentals, Object-Oriented Programming became an important next step. Concepts such as classes, objects, constructors, encapsulation, inheritance, polymorphism, and abstraction helped me understand how larger software systems can be organized.

OOP changed the way I looked at programming because I could now model real-world entities as objects and create reusable structures for larger projects.

SQL

Learning SQL introduced me to databases and the way applications store and retrieve information. I learned how tables are structured and how SQL commands can be used to insert, update, delete, and retrieve data.

Understanding primary keys, foreign keys, relationships, and joins also helped me see how different parts of an application communicate with stored data.

SELECT name, email
FROM students
WHERE age > 18;

Projects

Projects became one of the most valuable parts of my learning experience. Instead of only studying individual concepts, projects gave me a reason to connect those concepts together.

Building systems such as student management applications and database-based projects helped me practice programming, OOP, file handling, SQL, database design, and problem-solving in a practical environment.

  • Student management: Working with student records and academic information.
  • Airline system: Designing entities such as airports, aircraft, flights, bookings, tickets, and payments.
  • Database projects: Practicing tables, relationships, queries, and joins.
  • Web projects: Applying programming and design concepts to useful interfaces and websites.

Certifications

Alongside university learning, certifications helped me explore technologies and topics outside the classroom. Completing structured courses gave me opportunities to learn from different instructors and practice skills through guided material.

Certifications are useful, but I have learned that the real value comes from applying what I learn. A certificate can show that I completed a course; projects and practical work show how I can use that knowledge.

University experience

University has given me a structured environment to learn Computer Science fundamentals. Courses, assignments, projects, presentations, and exams have all contributed to my understanding of the field.

One of the biggest lessons from university has been learning how to manage multiple subjects and deadlines while continuing to improve technical skills independently.

Learning AI

As Artificial Intelligence became increasingly important in technology, I started exploring AI and the way modern AI tools can be used in software development and productivity.

Learning about AI also made me interested in automation and the possibilities of combining programming skills with intelligent tools. I see AI as an additional skill that can complement traditional Computer Science knowledge rather than replace its fundamentals.

Internships

Internships provide an important bridge between academic learning and professional work. They create opportunities to work with real requirements, deadlines, collaboration, documentation, and practical development workflows.

My internship experiences and applications have helped me understand the importance of communication, consistency, learning quickly, and delivering work instead of only studying concepts.

Challenges

My journey has not always been easy. There have been programming errors that took hours to understand, concepts that initially seemed confusing, and projects where the first solution did not work as expected.

These challenges taught me an important lesson: getting stuck is a normal part of learning Computer Science. Debugging, searching for the cause of a problem, testing different solutions, and trying again are all part of becoming a better developer.

"Progress in Computer Science is often made one bug, one concept, and one solved problem at a time."

Future goals

My goal is to continue building a strong foundation in software development while expanding my knowledge of AI, automation, databases, and modern web technologies.

I want to work on practical projects that solve real problems, gain professional experience, and continue learning throughout my career. The technology landscape changes quickly, so staying curious and continuously improving will always be an important part of my journey.

Conclusion

My journey into Computer Science is still in progress. From starting with basic programming to learning C++, OOP, SQL, databases, web development, and AI, every stage has added another piece to my understanding of technology.

The most important lesson has been that Computer Science is a continuous learning process. There will always be another technology to explore, another problem to solve, and another project to build.

The journey is still being written — and the next project is always another opportunity to learn. 🧡
